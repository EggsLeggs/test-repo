# test-repo

## Simple Todo App

A super basic todo app that runs on GitHub Pages for testing other projects.

### Features
- ✅ Add, complete, and delete todos
- ✅ Local storage persistence (survives page refresh)
- ✅ Statistics tracking
- ✅ Clean, modern UI

### Usage
1. Enable GitHub Pages in repository settings
2. Set source to this branch
3. Access at `https://EggsLeggs.github.io/test-repo/`

The app is self-contained in `index.html` - no build process needed!
